# BURGER & BITE — demo web ilova

## Ishga tushirish
1. ZIP faylni oching.
2. `index.html` faylini brauzerda oching. Internet ulanishi rasmlar va Google Fonts uchun kerak.
3. Yoki papkada terminal ochib `python -m http.server 8000` buyrug‘ini bajaring va `http://localhost:8000` manziliga kiring.

## Imkoniyatlar
- Uzbek tilidagi SPA ko‘rinishlar: bosh sahifa, menyu, auth, profil, tracking, filiallar, biz haqimizda.
- Qidiruv, kategoriya filtri, narx bo‘yicha saralash.
- Taom tafsiloti, pitsa o‘lchami va qo‘shimchalar narxi.
- Savat, miqdor boshqaruvi, promo kodlar PROMO10 va FAST20.
- 100 000 so‘mdan yuqori buyurtmaga bepul yetkazish.
- Demo ro‘yxatdan o‘tish/kirish, profil va buyurtmalar localStorage'da.
- Checkout, buyurtma kvitansiyasi va demo buyurtma kuzatuvi.
- Sevimlilar, toast bildirishnomalari, filiallar va feedback formasi.

## Muhim eslatma
Bu frontend demo loyiha. Login localStorage asosida simulyatsiya qilinadi; haqiqiy xavfsiz autentifikatsiya, ma'lumotlar bazasi, admin panel, kuryer GPS kuzatuvi va Click/Payme/Uzcard to‘lovlari uchun alohida backend hamda rasmiy provayder integratsiyasi zarur. Taqdim etilgan filial ma'lumotlari va narxlar demo kontentdir. Mahsulot rasmlari Unsplash manbalaridan yuklanadi.
